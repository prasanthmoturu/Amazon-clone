# Amazon Clone 🛒

A front-end clone of the Amazon homepage built using HTML and CSS.

## 🚀 Technologies Used

* HTML5
* CSS3

## ✨ Features

* Amazon-style navigation bar
* Search bar
* Product/category sections
* Product images and cards
* Responsive layout
* Footer section
